# Linden: growth & height tracker (iOS)

**Growth, beautifully understood.** An iOS app for honest height-growth tracking:
- real CDC growth charts and percentiles
- an adult-height estimate that shows its reasoning and is never sold as a guarantee
- growth speed and family-height context
- calm daily habits
- a doctor-ready PDF report
- **Ask Linden**, a growth assistant that runs on Apple's on-device model

Private by design: no accounts, no server, no tracking.

## Structure
- `Sources/GrowthEngine`: growth science only (CDC reference, percentiles, velocity, scenario); unit-tested
- `Sources/GrowthCore`: platform-independent logic. Covers profiles, habits, notifications, StoreKit-neutral entitlements, reports and PDF, Ask Linden safety and grounding. Swift 6, unit-tested on Linux and macOS.
- `Sources/DesignSystem`: SwiftUI tokens and components
- `Sources/AppFeatures`: SwiftUI screens, plus the StoreKit 2, UserNotifications and Foundation Models adapters
- `App/`: iOS app target
  - XcodeGen spec
  - icon and privacy manifest in `Resources/`
  - local StoreKit configuration
  - StoreKit and UI tests
- `site/`: public privacy, terms and support pages, generated by `scripts/build_site.py`
- `scripts/`:
  - CDC data generation and verification
  - simulator screenshots
  - App Store screenshot composition
  - iOS test runner

## Run
```sh
swift test                      # core tests (macOS or Linux)
brew install xcodegen           # once, on a Mac
cd App && xcodegen generate && open GrowthApp.xcodeproj   # Xcode 26, iOS 17+ (Ask Linden AI needs iOS 26 + Apple Intelligence)
scripts/run_ios_tests.sh        # StoreKit + UI tests on a simulator
```

No third-party dependencies, no backend, no API keys.
